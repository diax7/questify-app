# T-613 plan: event info page builder and one extra custom page (tier B)

FR-1835. Builds on T-606/T-610 (`event.config.layout`, ADR-391, ADR-395). No migration, no second content store, no new route.
Pictures wait for Q-149 and are split to **T-613b**; the page is text, lists and links.

## Data

- `layout.info = {order, hidden}`: the info page's sections `about`, `venue`, `when`, `schedule`, `faq`, `contacts`, `rules`
  (default order as the page always was, About first). `rules` is protected; `schedule` starts hidden and needs the agenda switch.
- `layout.content` gains `about` ({ar, en}), `faq` (≤12 `{question, answer}`), `contacts` (≤5 `{label, kind, value}` with kind email,
  phone or link) and `page` (`{title, blocks}` with 1 to 12 parts: heading, text, list, link) or null.
- Home gets one block, `page`, after the quick links: a card with the page's title that opens the page. Hiding it takes the page
  off the phone (the composed content carries a section's words and the page only while they are shown).
- Same cleaning and limits as Home's words (`content-read.ts` is the shared reading; `info-content.ts` holds the new parts).
  Links are https only with a full host; an email has no `%`, `?`, `&` or space; a phone number is 7 to 15 digits.

## App

`info.tsx` draws `infoSections(featureOn, layout.info)` in order (About, venue, when, agenda link, questions, contacts, rules), then the
help link. `page.tsx` is the extra page. Contacts open the mail or phone app; a website or a link part asks first. A damaged entry
or part is left out, a page with no valid part is no page.

## Dashboard

The Layout page gets an "Event info page" list (drag, move buttons, show switch, Edit on About, FAQ and Contact), an editor under
it, an "Extra page" row in the Home list whose editor adds, fills and removes the page (removing asks first), and an "About the
event" and an "Extra page" screen in the live preview. Save waits until the words pass the server's own check.

## Tests

shared (readers, strict check, layout lists, validation, presets), API int (save, order, hidden draft not composed, refusals, control
characters, preset keeps, damaged stored value, other organizer and stranger), app logic (`info-page.test.ts`), web lib (editor
problems, preview), one browser spec (order, write, preview, save, remove).
