# T-610 plan: Home editor, new blocks and the banner (tier B)

FR-1828, FR-1829, FR-1830, FR-1831. Builds on T-606 (`event.config.layout`, ADR-391). No migration, no second layout store.
Images (a banner slide's picture, any picture in a block) wait for Q-149 and are split to **T-610b**; a banner slide is text on
the accent colour with a tap action until then.

## Data

`event.config.layout` gains `content` next to `bar` and `home`:

- `home.order` / `home.hidden` list the built-in blocks and the organizer's cards as `card:<id>`. New built-in blocks:
  `banner`, `featured`, `podium`, `quickLinks`. `podium` is **off by default** (a stored layout without it reads it as hidden), so
  no live event gains a block on deploy. The other three draw nothing until they have content.
- `content = {banner: slide[≤5], quickLinks: link[≤6], featured: {kind: quest|reward, id} | null, cards: card[≤6]}`; a card is
  `text {title, body}` or `countdown {label, at, atZero: hide|message, message}`; every text is `{ar, en}`.
- Tap actions: `none`, `agenda`, `maps`, `shop`, `quest {questId}`, `link {url}` (https only, full host, no user info, ≤300).
- Text is plain: invisible and control characters removed, Western digits, length limits per field, at least one language where
  required. The app and the preview draw it as text, never as HTML or Markdown; nothing in it becomes tappable.

## Safe on a damaged value

`readHomeContent` is tolerant (drops a bad item, never throws, no `\p{}` regex so release Hermes is safe); `checkHomeContent`
is the strict request check (cleans, then refuses with a path). The composed configuration carries only the content of **shown**
blocks, so a hidden draft never reaches a phone. A preset (and "Reset to default") arranges the Questify blocks and keeps
every card and all content; cards follow the built-in blocks.

## App

`HomeKey = HomeBlock | card:<id>`; Home draws each key in the layout's order. Banner: one slide at a time, auto-advance every 5 s
(off with reduce motion or after a touch), swipe, dots only for two or more slides. Quick links, featured quest or reward (read
from the player's own quests and shop reads, hidden when not found or switched off), podium from the ranking read, text card,
countdown card (zero hides it or shows its message). A web link asks before it opens.

## Dashboard

Layout page: the Home list gains the new blocks; each block with content has an Edit button opening its editor under the list;
"Add text card" and "Add countdown" append a card; a card can be removed after a confirmation. The preview shows the unsaved
content. "Reset to default" (confirmed) applies Questify's default arrangement.

## Tests

shared (content read/check, layout read/compose/preset), API int (save with content, refusals, hidden content not composed,
presets keep content, outsider), app logic (tap routes, slider steps, countdown view), web lib, one browser spec.
